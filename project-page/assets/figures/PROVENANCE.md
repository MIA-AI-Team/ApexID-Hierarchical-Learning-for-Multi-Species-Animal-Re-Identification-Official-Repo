# Figure provenance

Every raster on the project page is derived from the ApexID paper's own figures, produced by the authors. No stock or generated imagery is used.

| File | Source in the paper |
| --- | --- |
| `apexid_hierarchical_loss.webp` | Figure 1, ApexID Hierarchical Loss overview |
| `closed_set_cmc.webp` | Closed-set CMC curves, all three backbone families |
| `scorecam/<backbone>_<loss>_<dataset>.webp` | ScoreCAM figure panels, re-cut into equal overlay, heatmap and image panels |
| `../og.jpg` | Figure 1 on a 1200×630 white canvas for link previews |

Animal images inside the figures come from ELPephants, Bristol Gorillas and GCN-ID and keep their original licenses. Private jaguar evaluation imagery is not included.
